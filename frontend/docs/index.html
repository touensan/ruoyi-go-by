项目使用指南

一个可直接运行的 Go 管理后台

RuoYi-Go BY 以 Go、Gin、GORM 和 Vue 3 为基础，保留用户、角色、菜单、配置、日志与代码生成能力，并补充支付、邮箱和系统设置工作台。

Go 服务端

单体 Go 服务负责鉴权、RBAC、系统管理、数据访问、文件上传和常用业务接口，默认使用 MySQL 与 Redis。

Whiteyun Vue 管理端

Vue 3、Vite、TypeScript 和 Element Plus 组成持续维护的默认前端，同时保留冻结的 RuoYi Vue 兼容版本。

先使用示例配置，再接入真实服务

仓库中的配置、账号、支付和邮件字段只用于本地开发。部署前请替换数据库、Redis、JWT 密钥和默认账号，并确认没有提交生产凭据。

开始准备运行环境
快速开始

从源码到后台，只要四步

  1. 1

    准备 Go、MySQL 和 Redis

    使用 Go 1.25+，准备 MySQL 5.7.8+（兼容 MySQL 8）和 Redis。确保服务地址、端口和账号可用。

  2. 2

    复制并填写示例配置

    复制 application-example.yaml 为 application.yaml，只在本机或受控部署目录填写真实连接信息。

  3. 3

    初始化数据库并安装依赖

    导入 ruoyi.sql，再执行 go mod tidy。示例账号首次登录后必须立即修改密码。

  4. 4

    启动服务并打开管理端

    运行 Go 服务与前端开发服务器，或先构建管理端后由 Go 服务托管 /admin/ 静态文件。

PREPARE准备数据库与缓存
CONFIGURE填写本地运行配置
RUN进入后台开始开发

本地启动命令

cp application-example.yaml application.yaml
go mod tidy
go run main.go

# 新终端：启动默认管理前端
cd frontend/whiteyun-vue
npm ci
npm run dev
工程结构

按职责组织源码

后端、默认前端、兼容前端和文档入口彼此独立，便于按需替换界面或部署静态资源。

目录用途
app/控制器、服务、模型、DTO、校验器和路由。
common/验证码、上传、密码、Excel、UUID 等通用能力。
framework/数据库、Redis、响应、日期时间等基础设施封装。
frontend/whiteyun-vue/当前默认的 Whiteyun Vue 管理端。
frontend/ruoyi-vue/冻结的 RuoYi Vue 旧视觉兼容版本。
frontend/docs/本公共文档页的静态源码与构建资源。
后台能力

常用管理能力已经准备好

  1. 1

    用户与权限

    通过用户、角色、菜单和部门维护 RBAC 权限，动态路由会根据当前账号权限生成。

  2. 2

    系统运行

    提供登录日志、操作日志、在线用户、定时任务、缓存和服务监控等常用运维入口。

  3. 3

    扩展工作台

    系统设置集中管理站点、支付和邮箱；工具箱提供代码生成与接口文档兼容入口。

进入管理后台登录后从动态菜单查看当前账号可用的系统、监控和工具模块。 查看正式版本从 GitHub Releases 下载源码压缩包和对应版本说明。
配置与工具

项目补充的差异功能

站点配置统一维护站点名称、Logo、SEO、版权、备案和客服信息。
支付配置支持易支付 V1/V2、支付宝和微信参数，提供回调地址生成和测试入口。
邮箱配置支持 SMTP、QQ 邮箱、Gmail 和自定义服务器，并提供发送测试。
代码生成支持数据表筛选、导入、预览、同步、生成和下载入口。
接口入口/swagger-ui/ 保留兼容占位页，实际接口以 Go 路由与项目文档为准。
支付商户号、密钥、SMTP 密码和 JWT 密钥均不会随公共源码提供。请把真实值放入部署环境的配置文件或密钥管理系统。
前端选择

默认体验与旧版兼容并存

新项目建议使用 Whiteyun Vue；需要继续兼容旧若依视觉或已有二次开发时，再选择冻结的 RuoYi Vue。

WHITEYUN VUE

当前默认前端。持续维护白云风格、主题切换、响应式布局和授权工作台。

RUOYI VUE

旧视觉兼容版本。保留用于迁移和已有定制，不再接收常规界面更新。

BUILD OUTPUT

生产构建统一输出到 web/admin，由 Go 服务以 /admin/ 对外提供。

反向代理建议

让 Nginx 或宝塔站点负责 HTTPS，Go 服务只监听受控端口；正式环境同时配置 systemd 自动拉起、日志轮转、数据库备份和回滚目录。

常见问题

遇到问题时，先检查这里

为什么访问根路径进入后台？当前 Go 服务把根路径兼容重定向到 /admin/；公共使用指南固定在 /docs/。
为什么刷新后台页面不会 404？生产服务会为 /admin/* 回退到管理端 index.html，再由前端路由渲染当前页面。
为什么文档页没有登录？这是公共使用指南，只介绍项目能力和部署方式；需要操作后台时再进入管理端登录。
可以继续使用旧版前端吗？可以。构建前设置 APIAUTH_ADMIN_FRONTEND=ruoyi-vue，但新功能和视觉更新优先维护 Whiteyun Vue。
