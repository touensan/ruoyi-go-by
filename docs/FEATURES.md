# 当前 Go 原生主线功能范围

本页描述 v1.1.3 原生若依主线；v1.2.0–v1.4.0 Whiteyun 支线的积分、充值入账、兑换等不能套用到当前主线。版本与附件关系见 [VERSIONS.md](VERSIONS.md)。

| 能力 | 当前实现与边界 |
| --- | --- |
| 统一后台 | 若依 Vue 3 / TypeScript，同一登录与账号体系，RBAC 单向继承与菜单/路由/接口控制见 ARCHITECTURE.md |
| 系统管理 | 用户、角色、菜单、部门、岗位、字典和参数管理；个人资料、密码与头像 |
| 支付 | 易支付 V1/V2 配置、真实网关测试请求（商户、下单、查询等）及回调验签；当前没有持久订单账本、幂等入账、钱包或兑换体系 |
| 邮件 | SMTP 配置和真实发送测试调用；不是仅保存配置，也不代表已完成真实供应商送达验收 |
| Redis | INFO、DBSize、SCAN、读取和清理；不是 Rust 的限定缓存前缀实现，ClearAll 使用所选 Redis 数据库的 FLUSHDB，会影响同库会话等数据 |
| Excel | Excelize 用户模板与 XLSX 导入/导出；导入逐行处理并报告成功/失败，不是 Rust 的整批事务导入 |
| 定时任务/任务日志 | 当前没有任务存储或调度器；相关接口返回 501，不再假装新增、执行、删除或导出成功 |
| 代码生成 | 真实数据表与列结构查看；完整模板生成、配置保存、导入/同步、生成下载尚未实现，相关接口返回 501 |
| 公告 | 没有公告持久化与已读记录；管理接口返回 501，顶部通知保留空列表并明确 supported=false 以兼容共享布局 |
| API 文档页 | 兼容说明页，不是自动生成的 Swagger UI |

接口返回 501 表示未执行该操作，不是权限不足或已经排队。存在页面、按钮或路由不等于后端已实现；不能用兼容占位响应作为功能验收证据。各模块真实实现与测试记录见源码和 [DEVELOPMENT.md](DEVELOPMENT.md)。
