# RuoYi-Go BY v1.4.0

本版本把 DNSR1 与 Whiteyun-APIAuth 已验证的积分和兑换模式沉淀为通用底座，并完成
“管理菜单 + 我的服务分界线”的默认信息架构。

## 主要变化

- “我的服务”改为侧边栏分界线，用户功能直接显示，不再嵌套在父菜单中。
- 管理员继续使用同一套用户工作台，并额外看到积分运营、系统管理等管理菜单。
- 新增通用积分账户、积分流水、人民币充值订单和易支付回调自动入账。
- 新增任务、任务审核、可转让积分兑换码、用户兑换和后台批量生码。
- 兑换码只保存 HMAC 摘要和掩码，完整明文仅创建时返回一次。
- 新增可独立开关的雨云任务提供商，通过 `X-Api-Key` 查询下级用户关系。
- 雨云默认关闭，不携带真实密钥；其他项目可以完全不启用或继续扩展新提供商。

## 升级

1. 备份数据库、配置和当前静态资源。
2. 从 `v1.2.x` 升级时先执行 `sql/upgrade/v1.3.0-user-workspace.sql`。
3. 执行：

```sql
SOURCE sql/upgrade/v1.4.0-points-exchange.sql;
```

4. 更新后端与 `frontend/whiteyun-vue` 静态资源。
5. 普通用户验证“我的服务”分界与积分/兑换页面；管理员再验证积分运营菜单。

生产环境必须使用高强度 JWT 密钥，因为兑换码 HMAC 密钥会从 JWT 密钥派生。雨云
`X-Api-Key`、支付密钥和邮件凭据不得提交到 Git。
