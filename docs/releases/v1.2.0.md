# RuoYi-Go BY v1.2.0

这是 Whiteyun Vue（白云风格前端）成为默认管理端后的首个正式版本。

## 版本线

- `v1.2.0`：默认使用 Whiteyun Vue，作为后续持续维护版本。
- `v1.1.2`：RuoYi Vue 旧版前端基线，保留兼容但停止常规更新。

## 主要变化

- 新增独立的 `frontend/whiteyun-vue`，统一日间/夜间主题、三种导航布局、标签页、
  表单、弹层、登录页和后台首页。
- 完成桌面、平板和手机端响应式适配。
- 保留 `frontend/ruoyi-vue` 作为冻结兼容前端。
- 默认构建切换到 Whiteyun Vue；可通过
  `APIAUTH_ADMIN_FRONTEND=ruoyi-vue` 显式构建旧版前端。
- 示例配置版本更新为 `1.2.0`，README 增加两条前端版本线说明和最新演示截图。
- 数据库继续以 MySQL 5.7+ 为基准，并兼容 MySQL 8。

## 升级提示

直接执行 `frontend/build-admin.sh` 将构建 Whiteyun Vue。仍需旧若依视觉的部署，
请显式设置：

```bash
APIAUTH_ADMIN_FRONTEND=ruoyi-vue frontend/build-admin.sh
```

两套前端共享现有后端 API、动态菜单和权限模型。
