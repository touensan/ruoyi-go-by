# RuoYi-Go BY v1.3.0

本版本把 DNSR1 已验证的“管理员也是用户，只额外拥有管理能力”模式沉淀为
RuoYi-Go BY 的默认信息架构。

## 主要变化

- `/index` 改为所有登录账号共享的用户工作台。
- 新增“我的账户 / 个人资料”菜单，作为后续用户业务模块的默认挂载位置。
- `common` 角色改为“普通用户”，数据范围收紧为“仅本人”，不再拥有系统管理菜单。
- 超级管理员继续拥有全部菜单，因此会在用户工作台基础上看到管理入口。
- 非超级管理员采用 `common + 管理角色` 的角色组合，不复制另一套用户后台。
- 自助注册会校验并绑定启用状态的 `common` 角色，用户创建与角色关系在同一事务完成。
- 提供 MySQL 5.7+ 升级脚本，清理普通角色的系统管理权限并修复历史无角色账号。
- 修正示例配置中用户密码重试策略的 YAML 层级，复制后可被后端正确加载。
- 初始化与升级 SQL 显式使用 `utf8mb4` 客户端字符集，避免命令行导入中文菜单乱码。
- 修正 Whiteyun Vue 开发代理丢失 `/api` 前缀的问题，本地开发登录可直接连通 Go 后端。

## 升级方法

1. 备份数据库与当前应用版本。
2. 更新后端和 Whiteyun Vue 静态资源。
3. 执行：

```sql
SOURCE sql/upgrade/v1.3.0-user-workspace.sql;
```

4. 用普通账号确认只显示“工作台”和“我的账户”。
5. 用超级管理员确认同时显示用户空间与系统管理。

升级脚本不会删除项目自定义的非系统菜单映射。自定义管理员若不是超级管理员，需要
同时绑定 `common` 与所需管理角色。
